# Paws - Downloads

A cat that takes over your screen every 20 minutes of continuous work and makes
you take a break: short at first, longer the more you skip.

This repository hosts the installers and auto-update feed for Paws.
The source code lives in a private repository.

## Install

Download the latest version from the [Releases](https://github.com/mahupreti/paws-releases/releases) page:

- Windows: Paws-Setup-x.y.z.exe (installer, auto-updates) or Paws-Portable-x.y.z.exe.
  The app is unsigned, so SmartScreen will warn: click More info, then Run anyway.
- Linux: Paws-x.y.z.AppImage (auto-updates). Debian/Ubuntu: sudo dpkg -i paws_x.y.z_amd64.deb
